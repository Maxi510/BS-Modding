BS Tool

Crea tus mods facilmente

¿Qué es?

BS Tool facilita la introducción de assets, en la versión 1.0 reemplazando Texture2D . Abre el archivo de los assets originales para que, mediante un clic, puedas reemplazarlo, guardando los datos suficientes para la creación del zip.

Funciones

  • Crear mods.
  • Compatible con Ware u otro ModLoader que pueda cargar zip mediante el mismo sistema que Ware.
  • Modificacion de mas tipo de assets en futuras actualizaciones.
  • Requiere tener Java 25 instalado para ejecutarlo(JRE).

Información

Plataforma PC Multiplataformas
Lenguaje Java
